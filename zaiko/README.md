# 民泊 消耗品 在庫・発注アシスタント

在庫データと発注ルールをもとに、**発注が必要な消耗品を自動で検知**し、
**発注先ごとの発注方法に合わせた下書き**（注文リスト・メール文面・連絡メモ・買い物メモ）を提示する
「支援型」アシスタントです。最終的な確認・発注の実行は人（承認者）が行います。

## 使い方（デプロイ不要）

`民泊在庫発注_app.html` をブラウザで開くだけで動きます。
インストール・サーバー不要のスタンドアロン構成で、データはブラウザ内（localStorage）に保存されます。
サンプルの品目マスタ（民泊消耗品 21品目）が最初から入っているので、すぐに動作を確認できます。

> 本番運用では、GoogleスプレッドシートやDBをバックエンドにし、
> スタッフのアカウント認証と権限を連携させる想定です（既存の評価シートアプリと同じ GAS 構成に載せ替え可能）。

## 画面構成

| タブ | 役割 |
|------|------|
| 📊 ダッシュボード | 分類・状況ごとに**色分け**した在庫一覧。＋/−で在庫を即時調整 |
| 🧾 発注提案 | 発注点以下の品目を自動抽出し、**発注先ごとの下書き**を生成。金額見込みを自動計算 |
| 📦 入荷・履歴 | 発注済みの入荷確認（在庫へ自動反映）と、発注→納品の履歴 |
| 🗂️ 品目マスタ | 単価・発注点・発注先の改定、CSV取込（Excel/PDF台帳の移行）、**データ検証** |
| 📝 監査ログ | 在庫変更・発注確定・マスタ改定をすべて記録 |

## 権限（画面右上で切替）

誤発注防止のダブルチェックを、3段階の権限で表現しています。

| 権限 | 在庫調整・下書き・入荷 | マスタ編集 | **発注確定** |
|------|:---:|:---:|:---:|
| 閲覧者 | − | − | − |
| 発注担当者 | ✔ | − | − |
| 承認者（責任者） | ✔ | ✔ | ✔ |

発注の確定（在庫・履歴への反映）は**承認者のみ**が実行できます。

## 機能要件との対応

| 要件 | 実装 |
|------|------|
| 在庫数と発注点を照合し、発注が必要な品目を自動リストアップ | 発注提案タブ（`statusOf` / `在庫 ≦ 発注点` を自動抽出） |
| 発注先ごとに異なる発注フォーマットの下書きを自動生成 | `buildDraft`：アスクル=注文リスト／JTB商事=メール文面／大場金物=電話連絡メモ／ダイソー・ニトリ=買い物メモ |
| 発注ロット数・単価から発注金額の見込みを自動計算 | `suggestQty`（適正在庫までロット単位で切り上げ）× 単価 |
| 発注履歴を自動記録し、在庫数を更新 | 発注確定で履歴生成 → 入荷確認で在庫へ自動加算 |
| 品目・分類ごとに色分けした在庫ダッシュボード | 分類別グループ表示＋状況チップ（欠品/要発注/適正/過剰）で色分け |
| 単価・発注ルールの改定を反映しやすい構成 | マスタタブでセル直接編集。CSV入出力にも対応 |
| 表記ゆれ・空欄データを検知し確認を促す | `runValidation`：空欄・単価0・発注先/分類の未登録・コード重複・同名異発注先を検出 |

## 非機能要件との対応

- **即時性**：在庫の＋/−調整はその場で保存され、当日中にダッシュボードへ反映
- **シンプルUI**：専門知識がなくても分かる色分け＋チップ表示
- **権限管理**：閲覧／担当／承認の3段階。発注確定は承認者限定
- **認証情報の分離**：発注先のID・パスワードはアプリに保存しない設計
- **データ移行**：`コード,品名,分類,発注先,単位,在庫,発注点,適正在庫,発注ロット,単価` のCSVで既存台帳を取込
- **監査ログ**：操作日時・操作者・種別・内容を記録し、CSV出力可能
- **電話・現金対応**：大場金物＝電話連絡メモ＋現金持参額、ダイソー・ニトリ＝店頭買い物メモに対応

## CSV取込フォーマット

```
コード,品名,分類,発注先,単位,在庫,発注点,適正在庫,発注ロット,単価
A-101,歯ブラシセット,アメニティ,JTB商事,セット,18,30,80,50,42
```

1行目がヘッダー（`品名`/`コード` を含む）の場合は自動でスキップします。
発注先・分類は下記の規定値と一致させてください（表記ゆれは検証で警告されます）。

- 発注先：`アスクル` / `JTB商事` / `大場金物` / `ダイソー・ニトリ`
- 分類：`アメニティ` / `清掃用品` / `トイレ・キッチン消耗品` / `リネン・寝具` / `備品・設備`

発注先・分類の規定値を変える場合は、`民泊在庫発注_app.html` 内の `SUPPLIERS` / `CATEGORIES` を編集します。
