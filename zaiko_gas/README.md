# 民泊 消耗品 在庫・発注アシスタント（本番版 / GAS＋スプレッドシート）

在庫と発注点を照合して発注が必要な消耗品を自動検知し、発注先ごとの発注方法に合わせた
下書きを提示する「支援型」アシスタントの **本番運用向け** 実装です。

`../zaiko/` のスタンドアロン版（1人・お試し用）と違い、こちらは
**データをGoogleスプレッドシートで全スタッフ共有**し、**権限をGoogleアカウントで判定**します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | バックエンド。スプレッドシート読み書き・権限判定・発注/入荷処理 |
| `App.html` | フロントエンド（Apps Script テンプレート）。UIとサーバー呼び出し |
| `SETUP.md` | 導入手順（スプレッドシート作成〜ウェブアプリ公開） |

## セットアップ

**[SETUP.md](./SETUP.md) の手順に従ってください。** 要点だけ先に挙げると：

1. スプレッドシートを新規作成 →「拡張機能」→「Apps Script」
2. `Code.gs` を貼り付け、HTMLファイル `App` に `App.html` を貼り付け
3. スプレッドシートのメニュー「在庫アシスタント」→「初期セットアップ」を実行
4. `権限マスタ` シートにスタッフのメール＋権限（manager/staff/viewer）を登録
5. 「デプロイ」→「ウェブアプリ」で公開し、URLを配布

## スプレッドシートの構成（自動生成）

| シート | 内容 |
|---|---|
| `品目マスタ` | コード・品名・分類・発注先・単位・在庫・発注点・適正在庫・発注ロット・単価 |
| `発注履歴` | 発注ID・発注日・発注先・品目・数量・金額・状況（発注済/納品済）・納品日 |
| `監査ログ` | 日時・操作者・権限・種別・内容 |
| `権限マスタ` | メールアドレス・権限・表示名 |

## 権限（サーバー側で強制）

| 権限 | 在庫調整・下書き・入荷 | マスタ編集 | 発注確定 |
|---|:---:|:---:|:---:|
| viewer（閲覧者） | − | − | − |
| staff（発注担当者） | ✔ | − | − |
| manager（承認者） | ✔ | ✔ | ✔ |

ボタンの表示制御だけでなく、権限のない操作は `Code.gs` の `requirePerm_()` が
サーバー側で拒否します。発注確定は承認者のみ（誤発注防止のダブルチェック）。

## 機能・非機能要件との対応

機能要件（発注自動検知／発注先別の下書き生成／金額見込み計算／履歴記録・在庫更新／
色分けダッシュボード／単価・ルール改定への対応／表記ゆれ・空欄の検知）と、
非機能要件（即時反映／シンプルUI／権限管理／発注確定のダブルチェック／
Excel・PDF台帳の移行／監査ログ／電話・現金対応）を実装しています。
詳細な対応表はスタンドアロン版のREADME（`../zaiko/README.md`）を参照してください。

本版で特に強化した非機能要件：

- **即時性・共有**：データはスプレッドシートに保存。全スタッフが同じ最新状態を見る
- **権限管理**：Googleアカウント＝本人。操作者が監査ログに実名（メール）で残る
- **認証情報の分離**：発注先のID・パスワードはアプリに保存しない

## お試しだけしたい場合

導入前に動きを見るだけなら、`../zaiko/民泊在庫発注_app.html` をブラウザで開けば
インストール不要で同じUIを試せます（データはそのブラウザ内のみ）。
