# セットアップ手順（Google Apps Script 版）

在庫データ・発注履歴・監査ログを **Googleスプレッドシート** に保存し、
**Googleアカウントで権限を判定** する本番向け構成です。
既存の評価シートアプリと同じ「スプレッドシート＋Apps Script ウェブアプリ」の形です。

## 1. スプレッドシートを作成

1. Google Drive で新しいスプレッドシートを作成
2. 名前を「民泊 在庫管理」などに変更

## 2. Apps Script にコードを貼り付け

1. スプレッドシートの「拡張機能」→「Apps Script」を開く
2. 最初からある `コード.gs` の中身をすべて消し、**`Code.gs`** の内容を貼り付け
3. 左メニュー「＋」→「HTML」→ ファイル名を **`App`** にして、**`App.html`** の内容を貼り付け
   （ファイル名は拡張子なしの `App`。中身の `<!DOCTYPE html>…` をそのまま貼る）
4. 保存（💾）

> ⚠ HTMLファイル名は必ず **App**（大文字小文字も一致）にしてください。`Code.gs` が `App` を読み込みます。

## 3. 初期セットアップを実行

1. スプレッドシートを一度リロードすると、上部に **「在庫アシスタント」メニュー** が出ます
2. 「在庫アシスタント」→「初期セットアップ / 自分を承認者に」を実行
3. 初回は権限の許可を求められます → 「権限を確認」→ 自分のアカウント →「詳細」→「安全ではないページに移動」→「許可」
4. 完了すると、次のシートが自動作成されます
   - `品目マスタ`（サンプル21品目入り）
   - `発注履歴`
   - `監査ログ`
   - `権限マスタ`（実行したあなたが `manager`＝承認者として登録されます）

## 4. 権限を設定する（権限マスタ）

`権限マスタ` シートに、スタッフのGoogleアカウントのメールアドレスと権限を登録します。

| メールアドレス | 権限 | 表示名 |
|---|---|---|
| owner@example.com | manager | 代表 |
| staff-a@example.com | staff | Aさん |
| part@example.com | viewer | パートさん |

- `manager` … 承認者（発注確定・マスタ編集ができる）
- `staff` … 発注担当者（在庫調整・下書き作成・入荷確認ができる）
- `viewer` … 閲覧者（見るだけ）
- **未登録のアカウントは自動的に `viewer`（閲覧のみ）** になります

> 権限はサーバー側（Apps Script）で判定・強制します。ボタンを消すだけでなく、
> 権限のない操作はサーバーが拒否するので、誤発注・不正操作を防げます。

## 5. ウェブアプリとして公開

1. Apps Script エディタで「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」
3. 設定：
   - 説明：`在庫アシスタント v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**組織内の全員**（Workspace）
     ※ 誰が操作したかを記録するため、`Google アカウントでログイン` が必要な設定にしてください
4. 「デプロイ」→ 表示された **ウェブアプリURL** をスタッフに配布

## 6. 使い方（配布後）

URLを開くと、ログイン中のGoogleアカウントに応じた権限で在庫アシスタントが開きます。
全スタッフが同じスプレッドシートのデータを共有し、変更は即時に反映されます。

- 📊 ダッシュボード：分類・状況ごとに色分けした在庫一覧。＋/− で在庫調整
- 🧾 発注提案：発注点以下を自動抽出し、発注先ごとの下書きを生成
- 📦 入荷・履歴：入荷確認で在庫へ自動加算
- 🗂️ 品目マスタ：単価・発注点・発注先の改定、CSV取込、データ検証
- 📝 監査ログ：操作日時・操作者・種別・内容を記録

## 既存Excel/PDF台帳からの移行

1. 既存台帳を次の列順でCSV（UTF-8）に書き出し
   `コード,品名,分類,発注先,単位,在庫,発注点,適正在庫,発注ロット,単価`
2. アプリの「品目マスタ」→「⬆ CSV/Excelから取込」で読み込み
3. 発注先・分類は下記の規定値に合わせてください（表記ゆれは検証で警告されます）
   - 発注先：`アスクル` / `JTB商事` / `大場金物` / `ダイソー・ニトリ`
   - 分類：`アメニティ` / `清掃用品` / `トイレ・キッチン消耗品` / `リネン・寝具` / `備品・設備`

## 発注先・発注ルールを変える

発注先や発注方法の追加・変更は `Code.gs` の `SUPPLIERS` / `CATEGORIES` を編集し、再デプロイします。
単価・発注点・適正在庫・発注ロットは品目ごとの値なので、アプリの品目マスタ画面から変更できます。

## セキュリティ上の注意

- 発注先の **ID・パスワード等の認証情報はこのアプリに保存しません**。オンライン発注は各担当者が発注先サイトに直接ログインして行います。
- 発注の **最終確定は承認者（manager）のみ** が実行できます（誤発注防止のダブルチェック）。
- すべての在庫変更・発注・マスタ改定は監査ログに記録されます。
